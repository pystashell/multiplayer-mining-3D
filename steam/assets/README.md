# Steam visual assets

Do not upload placeholders to Steam. Add approved production artwork here only
after rights and visual review.

The desktop packager currently uses `app-icon.ico` and reports `icon=custom`.
The icon remains a technical preview until its final visual and rights review
is complete.

Current required Steamworks sizes (verified 2026-07-29):

- `app-icon.ico`: 256 x 256 application/shortcut icon source.
- Header capsule: 920 x 430.
- Small capsule: 462 x 174.
- Main capsule: 1232 x 706.
- Vertical capsule: 748 x 896.
- Library capsule: 600 x 900.
- Library hero: 3840 x 1240, artwork only.
- Library logo: transparent PNG, up to 1280 wide and/or 720 tall.
- Library header capsule: 920 x 430.
- At least five real gameplay screenshots: 1920 x 1080 or larger, 16:9.

Valve's current templates and rules remain authoritative:

- https://partner.steamgames.com/doc/store/assets
- https://partner.steamgames.com/doc/store/assets/rules
